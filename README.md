## 🧑‍💻 Sobre mí

Software Engineer con orientación **Backend** y más de 7 años de experiencia en **C# y .NET**. Me especializo en **cobranza y medios de pago de alto volumen**: microservicios con más de 50.000 transacciones diarias y picos de 150+ por minuto, con integraciones a Mercado Pago, Payway y MODO.

Trabajo con microservicios, APIs REST, arquitectura orientada a eventos (RabbitMQ), Clean Architecture y DDD, concurrencia, bases de datos SQL y NoSQL, tests automatizados y CI/CD. También tengo experiencia en frontend con Angular y React.
